# 💻 Craig Rosenblum

## 👨‍💻 About Me

Retired programmer who still codes because I enjoy solving problems. I spent a few decades working with web technologies, databases, programming languages, and servers, and I still enjoy learning how things work and figuring out how to make them work better.

These days, most of my coding is practical: if something is annoying, repetitive, unreliable, or missing a useful feature, I build a tool to fix it.

## 🛠️ What I'm Working On

- Python tools for managing and analyzing my Jellyfin media collection
- Scripts for detecting media and metadata problems
- Windows automation and batch-file tooling
- Docker and self-hosted services on my PC and Raspberry Pi
- Network services including AdGuard Home and Unbound

## 🔧 Things I've Built

### [Jellyfin Metric Score](https://github.com/crosenblum/jellyfin_metric_score)

A Python tool for evaluating media-library quality, metadata completeness, and structural consistency.

### [blint](https://github.com/crosenblum/blint)

A Windows batch-file linter designed to catch common scripting problems before they become bugs.
